LILITH.exe — Personal Intelligence Center

COMO ABRIR
1. Extraia a pasta LILITH-exe para um local no seu computador.
2. Abra a pasta no Visual Studio Code.
3. Abra index.html no navegador. Para melhores resultados, use a extensão Live Server.
4. Os módulos de dados públicos precisam de conexão com a internet.

MÓDULOS
- Data Explorer: pesquisa na Wikipédia em português.
- Weather Data: geocoding e previsão do Open-Meteo.
- World Indicators: dados públicos da API World Bank.
- Terminal: comandos simulados locais, sem acesso remoto.
- Notes: notas guardadas em localStorage do navegador.
- Password Lab: gerador local de senhas.
- Security Check: estimativa indicativa local da força de senha.

OBSERVAÇÕES
- Este projeto não coleta dados privados de terceiros, não rastreia pessoas e não acessa contas.
- As APIs públicas podem ter limites, indisponibilidade temporária ou políticas próprias.
- As notas são armazenadas no navegador usado para abrir o projeto. Não coloque informações sensíveis.
- A análise de senha é educativa e não verifica senhas vazadas.
- A fonte Google Fonts é usada para tipografia; caso não carregue, o site usa fontes alternativas.
